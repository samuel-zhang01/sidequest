One conductive thread

Sources and models can change. The loop contract does not.

↳
Any source → observationStrava, Garmin, GPS or manual data normalize to distance, time, pace, effort and freshness.
↳
Any model → structured proposalEvidence, uncertainty, question, intervention, success measure and safety stop.
↳
Friends → commitmentPeers deliver the nudge without receiving the private evidence state.
↳
Outcome → next stateCompletion, effort and symptoms become new evidence for reassessment.

Safety boundary

This POC describes running signals. It does not diagnose, clear someone for exercise or encourage pushing through warning symptoms.

Generation: deterministic-poc. The backend contract is ready for an LLM, but no model is claimed yet.

Private API + Postgres · source-aware · same-origin · one public port
